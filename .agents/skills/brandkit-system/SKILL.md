# Brandkit System — Hệ Thống Thiết Kế Nhận Diện Thương Hiệu Đẳng Cấp

Skill này đóng vai trò là Giám đốc Nghệ thuật (Art Director) và Kiến trúc sư Hệ thống Thị giác, hướng dẫn Agent và nhà thiết kế kiến tạo bộ nhận diện thương hiệu mang chuẩn mực của các identity studio quốc tế.

---

## 1. Tôn Chỉ Thẩm Mỹ (Visual DNA)

Bộ nhận diện thương hiệu chuẩn cao cấp phải thỏa mãn 8 tiêu chí:
- **Chủ đích (Intentional)**: Mỗi đường nét, màu sắc đều có lý do tồn tại.
- **Tối giản (Minimal)**: Giữ lại những gì cốt lõi nhất, loại bỏ họa tiết rườm rà.
- **Biên tập (Editorial)**: Bố cục tạp chí thời thượng, tỷ lệ khoảng trắng lớn (Negative Space).
- **Điện ảnh (Cinematic)**: Tông màu trầm tĩnh (Dark Charcoal / Slate / Off-Black), không dùng màu neon lòe loẹt.
- **Có chiều sâu (Layered Depth)**: Sử dụng chất liệu hạt mịn (subtle grain), lưới scanline hoặc hiệu ứng in ấn nhẹ nhàng.

---

## 2. Cấu Trúc Bảng Trình Diễn Thương Hiệu (Brand Presentation Board)

Một bảng tổng hợp nhận diện thương hiệu hoàn chỉnh (Brand Kit Board) bao gồm:

```
┌───────────────────────────────────────────────────────────────┐
│ 1. BIỂU TƯỢNG CHÍNH (Primary Logo Mark)                       │
│    - Dạng hình học tối giản, dễ nhận biết từ kích thước 16px  │
│    - Ý nghĩa biểu trưng sâu sắc, không vẽ hình minh họa phức tạp│
├───────────────────────────────┬───────────────────────────────┤
│ 2. HỆ THỐNG MÀU SẮC           │ 3. KIẾN TRÚC TYPOGRAPHY       │
│    - Màu nền: Charcoal/Zinc   │    - Tiêu đề: Display/Serif   │
│    - 1 Màu nhấn (Accent <80%) │    - Nội dung: Clean Sans     │
│    - Tuyệt đối cấm gradient tím│    - Tỷ lệ tương phản rõ nét │
├───────────────────────────────┴───────────────────────────────┤
│ 4. ỨNG DỤNG THỰC TẾ (Real-World Applications)                 │
│    - Khung giao diện ứng dụng (Clean App / Terminal Frame)    │
│    - Ấn phẩm văn phòng, card visit tối giản                   │
│    - Biển hiệu ngoài trời hoặc bao bì sản phẩm                │
└───────────────────────────────────────────────────────────────┘
```

---

## 3. Quy Tắc Phối Màu Chuẩn Xác (Color Calibration)

1. **Nền và Bề Mặt (Surfaces)**:
   - Tông tối: Dùng than chì ấm (Charcoal `#121214`), xám đá sâu (Zinc-950 `#09090b`). Cấm dùng đen tuyệt đối (`#000000`).
   - Tông sáng: Dùng trắng ngà (Off-White `#f8f9fa`), giấy kem (`#f4f1ea`). Cấm dùng trắng chói gắt.
2. **Màu Nhấn (Accent Color)**:
   - Chỉ chọn duy nhất **1 màu nhấn chủ đạo** (ví dụ: Cam hổ phách `#f59e0b`, Xanh coban `#2563eb`, Xanh rêu `#10b981`).
   - Giữ độ bão hòa dưới 80% để duy trì vẻ sang trọng.
3. **Danh mục cấm kỵ**:
   - Nghiêm cấm hiệu ứng tỏa sáng tím/xanh neon kiểu "AI Slop".
   - Nghiêm cấm gradient 3-4 màu lòe loẹt không kiểm soát.
