# Hướng Dẫn Bắt Đầu Nhanh (Getting Started)

Chào mừng bạn đến với **HuyNex Agent Kit** — Hệ thống kỹ năng và quy tắc chuẩn hóa cho AI Coding Agents.

---

## 1. Yêu Cầu Hệ Thống
- Python 3.10 trở lên.
- Một trong các AI Agent Clients: OpenAI Codex CLI, Claude Code, Google Antigravity, hoặc Cursor IDE.

---

## 2. Cài Đặt Trong 30 Giây

### Bước 1: Clone Repository
```bash
git clone https://github.com/huylinhhg/HuyNex-Agent-Kit.git
cd HuyNex-Agent-Kit
```

### Bước 2: Xem Danh Mục Kỹ Năng
```bash
python3 scripts/install.py --list
```

### Bước 3: Xem Trước Thay Đổi (Dry-Run)
```bash
python3 scripts/install.py --all --check
```

### Bước 4: Cài Đặt Chính Thức
```bash
python3 scripts/install.py --all
```

Sau khi cài đặt xong, hãy mở phiên làm việc mới trong Agent của bạn để tận hưởng các kỹ năng chuyên sâu!
